# Catppuccin

> Catppuccin theme pack for Asyar — soothing pastel colors in Mocha, Macchiato, Frappé, and Latte.

`org.asyar.catppuccin` is a Tier 2 Asyar theme (theme · macOS, Linux, Windows) with all four official flavors:

- **Mocha** (dark)
- **Macchiato** (dark)
- **Frappé** (dark)
- **Latte** (light)

## Permissions

No special permissions required.

## Install

Install from the [Asyar Store](https://asyar.org/extensions).

Then activate the theme and pick a flavor under **Settings → Appearance → Theme**.
