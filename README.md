# Catppuccin

> Catppuccin Mocha theme for Asyar — soothing pastel colors for the night owl.

`org.asyar.catppuccin` is a Tier 2 Asyar theme (theme · macOS, Linux, Windows).

## Permissions

No special permissions required.

## Install

Install from the [Asyar Store](https://asyar.org/extensions).

Then activate the theme under **Settings → Appearance → Custom Themes**.
